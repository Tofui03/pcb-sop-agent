# 波峰焊 SOP

样例文件，只给检索练习用，不是产线作业指导。

## 1. 目的

本样例描述实验台上的波峰焊顺序。里面的温度和速度都是编出来的，不能拿去设定设备。

## 2. 准备

1. 核对样例工单上的助焊剂名称。
2. 看预热区的样例显示是否亮着。
3. 把轨道宽度调到样例板的宽度。
4. 确认锡槽盖已经合上。

## 4.3 温度

锡温在本样例里只是一个假窗口。链速跟着样例板走，不做真实工艺判定。
